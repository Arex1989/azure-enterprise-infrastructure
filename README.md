# Azure Enterprise Infrastructure

## Project Overview

This project demonstrates the design and implementation of a secure,
supportable Azure infrastructure environment for a fictional
500-user organisation.

The project focuses on practical cloud engineering skills including:

- Azure networking
- Network segmentation
- Microsoft Entra ID
- Role-Based Access Control (RBAC)
- Virtual machines
- Azure Storage
- Monitoring and logging
- Backup and recovery
- Infrastructure as Code with Terraform

The environment is designed around security, least privilege,
operational visibility, resilience and supportability.

## Objectives

The objectives of this project are to:

1. Design a secure Azure network architecture.
2. Deploy compute workloads into segmented subnets.
3. Apply identity and access controls using Microsoft Entra ID.
4. Implement monitoring and operational visibility.
5. Configure backup and recovery.
6. Document the architecture and design decisions.
7. Rebuild the environment using Terraform.
